# Repo-specific instructions for Claude Code

## Commit / PR attribution

Do NOT add any Claude/AI attribution to commits or pull requests:
- No `Co-Authored-By: Claude ...` trailer.
- No `🤖 Generated with Claude Code` line (or any variant).

Commit messages and PR descriptions should look exactly as if the human
author (trelowney) wrote them, with no mention of Claude/AI as a creator
or co-author anywhere.
